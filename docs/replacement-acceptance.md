## 3. 検査の分担

- 自動: 索引、IDと参照、保持対象のハッシュ、データの整合、保存保護、失敗時の変更なし。
- AIと人: 主張・説明・構成、視覚的な問題の判断、修正方針。
- PowerPoint等の実アプリ: 文字・表・グラフの編集、マスター/テーマ変更、ページ追加、保存して開き直す操作。
- 複数環境: 対応を宣言するWindows/Linux/Cloudでのフォントと描画。別アプリの表示まで未試験なら保証しない。

ハッシュの一致は内容の保持の証拠、描画の成功は表示経路の証拠、手動編集の成功は特定操作の証拠。それぞれを他の試験の代わりにしない。

## 4. 独立性の試験

エンジンの試験では、依存として許可した公開ライブラリ・描画ツール・自作ファイルだけを配置し、既存skillフォルダを参照できない状態にする。コードと設定のパス参照、実行履歴を確認する。

AIの試験では、使用AI、モデル、実際に読み込んだ指示・資料・ツールを記録する。このCodexアプリでは付属指示の影響があり得るため、このチャット内の試験だけで自作skill単独の効果と断定しない。独立環境の方式は別途決める。
