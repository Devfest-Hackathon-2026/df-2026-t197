# 受入条件・検証計画

## 判定の段階

「実装あり」「自動試験済み」「表示確認済み」「編集操作確認済み」「クラウド確認済み」を分ける。未実施を合格にしない。

| ID | 試験 | 合格条件 | 確認方法 |
| --- | --- | --- | --- |
| T01 | 入力検証 | 不明キー、重複ID、範囲外の図形を拒否 | 自動 |
| T02 | 基本生成 | PPTX必須部品、ページ数、タイトルが一致 | 自動 + PowerPoint |
| T03 | 日本語 | 欠字・不自然な折り返しがない | 全ページの表示 |
| T04 | 編集性 | 本文・表・グラフデータを編集できる | PowerPoint操作 |
| T05 | マスター | 共通タイトル/本文と自由配置文字の継承範囲を区別できる | 操作 + XML |
| T06 | 出典・ノート | ソース情報がノートに残る | 構造 + 操作 |
| T07 | 修正 | 対象外構成データ不変、原本保持、不正patchで出力なし | 自動 |
| T08 | 画像パス | 資産フォルダ外への参照を拒否 | 自動 |
| T09 | 過密 | 長い説明・小さい字を警告し、黙って削らない | 自動 + 表示 |
| T10 | 構造 | 必須部品と内部参照が存在 | 自動。XSD・Office動作の保証ではない |
| T11 | 再生成 | 同じ内容とページ順を維持 | 内容を比較。バイト一致は不要 |
| T12 | API | health、正しい入力、不正入力、本文上限、パス拒否 | ローカルHTTPとクラウド |
| T13 | skill利用 | 読み取り・実行の履歴が確認できる | 実験履歴 |
| T14 | 論文の正確さ | 数値、条件、図表、主張が原本に一致 | 論文との照合 |
| T15 | 比較 | 同一条件で手直し箇所を数えられる | 人による評価 |

## 視覚確認の記録

各問題にページID、要素、現象、利用への影響、修正、再確認結果を付ける。文字サイズの目安は本文24pt、図表18ptを初期値とするが、指定されたテンプレートや付録では理由を添えて調整する。サイズだけで読めると判断しない。

## 比較実験

同じ論文・参考資料・依頼文・発表条件を使う。モデル・指示・実行環境に差があれば記録し、skillだけの効果と断定しない。内容・可読性・編集性ごとに、直したい箇所と修正時間を記録する。既存skill利用未確認の2資料は観察例とし、厳密な既存skillベースラインとは区別する。

## 現在の証拠

実行結果はローカルの `out/` に記録する。ここは試験計画であり、合格結果の一覧ではない。
