# 生成実験の記録項目

私有の資料・依頼文・スクリーンショットは非公開の作業フォルダに保存する。公開する場合は権利と個人情報を確認したものだけにする。

- 実験ID・日時・担当:
- 入力論文・版・ファイルハッシュ:
- 参考資料・利用目的（参考/実テンプレート/内容抽出）:
- 発表時間・聴衆:
- 実際に投入した依頼文:
- AIサービス・実際のモデル名・生成設定:
- 自作skillの版・ハッシュ:
- 他に読み込まれたskill・会話の前提:
- skillを読んだことが確認できる実行履歴:
- 生成・検査コマンドと結果:
- 出力PPTX・ハッシュ・プレビュー:
- 内容の問題:
- 表示の問題（ページID・要素・現象）:
- 編集操作の問題:
- 修正内容・修正時間・再確認結果:
- 残った問題・次のskill変更:

コードのハッシュや自己申告だけで、特定skillが使用されたと断定しない。スライドが作れたことと、論文の主張が正しいことも別に確認する。
