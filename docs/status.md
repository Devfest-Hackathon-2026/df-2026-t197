# 現在の対応状況

更新: 2026-11-07。現在の対応範囲を確認する入口。設計書の記載を実装済みと読み替えない。

| 領域 | 実装・確認したこと | 残っていること |
|---|---|---|
| skill | Codexでのリポジトリ内skillの発見、論文＋PPTXのXML編集経路、検査と描画による修正手順 | 改訂版を使った新規セッションでの生成比較、会議用途の手順 |
| 新規生成 | JSONから文字・図形・PNG/JPEG・表・棒/折れ線グラフ・ノート | AIによる構成生成の自動接続 |
| PDF | 本文・座標・指定領域PNG、ページ根拠の照合 | OCR、図表の自動認識、意味の自動検証 |
| 読取 | 表示順、図形ID、本文、参照、選択した継承情報 | 全書式計算、互換分岐、数式の完全解釈 |
| 編集 | 文字・段落・未結合表セル、局所書式、上位図形位置、PNG/JPEG追加・差し替え、図形削除、既存専用ノート | グラフ値、結合表、特殊効果、ノート作成、ネイティブ数式の作成 |
| ページ | 複製・対応レイアウトから追加・限定削除・順序変更 | セクション横断、任意資料の結合/分割 |
| 継承 | マスター/レイアウト/テーマの保持、特定レイアウトの反映試験 | root master/テーマの変更APIと汎用の反映検証 |
| 品質 | 入力・構造・保持検査、本文レイアウトと予定画像の照合、元の比率でのWindows PowerPoint描画 | 完全なXSD、文字切れ自動修正、Linux描画 |
| サービス | 構成JSONから生成するHTTP、Dockerfile | コンテナ実ビルド、AI/PDF/編集API、Cloud Run稼働 |

最新の自動試験はNode 79件＋Python 6件で計85件成功。テンプレート検査は旧稿のレイアウト混在を検出し、基準が揃った稿では指定した図・式の埋め込みも確認した。新規セッションでの自動選択から発表品質までの比較は別途行う。

操作契約は[pptx-edit.md](pptx-edit.md)を参照。

第一版の扱いは開発者向けのローカルプレビュー。公開用の合成データだけで`npm run smoke`を実行できる。大会提出の完成品とは区別する。
