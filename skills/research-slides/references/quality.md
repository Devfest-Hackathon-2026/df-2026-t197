# 確認と修正

生成・編集した最終候補を確認する。入力や環境の条件から、実施できなかった確認は未確認として残す。

## 1. 内容と変更範囲

論文の数値・条件・図表と照合し、説明の欠落や原文にない結論を探す。部分編集では対象外ページの内容・書式・ノートも保持対象にする。ハッシュは保持の証拠であり、意味や見た目の検証ではない。

## 2. 描画して問題を特定

WindowsとPowerPointが使える場合は、リポジトリルートから実行する。出力先は毎回新しくする。

```text
powershell -NoProfile -File scripts/preview.ps1 -InputPptx out/run/edited.pptx -OutputDirectory out/run/preview-v1
```

元の縦横比で描画される。最初に一覧で流れと同じ役割のページの揃い方を見て、次に各ページを表示サイズで読む。問題にはページ・図形等の対象と現象を付ける。テンプレート経路では元の該当レイアウトや参考ページとも見比べる。

| 現象 | 修正の判断と操作 |
|---|---|
| 本文が詰まる・語の途中で折り返す | 文章を短くし、意味のまとまりを保つ。共通枠に収まらなければページ分割や適したレイアウトを選ぶ。個別配置を意図した自由図形なら枠の調整も検討する |
| 文字が小さい・書体が揃わない | テンプレート経路では枠の継承、段落階層、自動縮小の有無を調べ、先にレイアウトと文章量を直す。個別書式の変更を依頼された場合は`set-text-style`。テンプレートなしの新規生成ではthemeや構成を修正する |
| 図が小さい・引き伸ばされる | 元画像の比率と出典を確認。対応するPNG/JPEGは`replace-image`でcontain配置。図内ラベルも読む |
| 無関係な装飾が残る | 残す必要がなければ`delete-shape`。参照が残る拒否を無視しない |
| 数値・出典が不正確 | 原本へ戻って照合し、対応する文字/表セルとノートを修正。根拠の検査を外して通さない |
| 同じ種類のページで配置がばらつく | 選択レイアウト、座標、個別上書きを比較する。共通書式を変える必要があっても、未対応のマスター編集を実施済みと扱わない |

修正操作の型と対象制限は[直接編集](editing.md)。新規構成の修正は[操作案内](operations.md)。検査を通すためだけに指定テンプレートを捨てない。

## 3. 再編集と最終化

- 候補PPTXを`inspect`で検査し、テンプレート経路では`check-template`も再実行する。変更後の候補を全ページ再描画し、見つけた文字切れ、重なり、書式のずれ、出典の誤りを修正する。修正を繰り返して解決できない場合は該当ページと理由を記録する。
- 可能なら検証用コピーで文字・表・必要なグラフの編集、保存・再読込を試す。共通書式や後日追加が要件なら、それぞれ操作して確認する。対応・環境がなく試せなかった操作は合格にしない。
- 本文・原図・出典・必要な項目が最終版に残っているか確認する。画像化の範囲と未解決事項を伝える。
- 実験ではモデル、入力、skillとコードの版、実際の読取/実行履歴、手直し箇所を記録する。skillファイルのハッシュだけで読み込みや単独効果を証明しない。
